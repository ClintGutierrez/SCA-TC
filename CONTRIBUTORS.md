## Cómo Contribuir

1. Fork el repositorio
2. Crea una rama para tu feature (`git checkout -b feature/AmazingFeature`)
3. Commit tus cambios (`git commit -m 'Add some AmazingFeature'`)
4. Push a la rama (`git push origin feature/AmazingFeature`)
5. Abre un Pull Request

## Proceso de Review

Los Pull Requests serán revisados por los mantainers del proyecto. Asegúrate de:

- Seguir la guía de estilo del proyecto
- Incluir pruebas si es posible
- Actualizar la documentación
- Incluir una descripción clara del cambio

## Reportar Bugs

Abre un Issue describiendo:
- Comportamiento esperado vs actual
- Pasos para reproducir
- Sistema operativo y versión de Node
- Capturas de pantalla si es aplicable

## Código de Conducta

Este proyecto se adhiere a un código de conducta de respeto y profesionalismo. Se espera que todos los contribuidores mantengan un ambiente inclusivo y acogedor.
